# Generated interface art

`Assets/_Project/Resources/UI/ActionIcons.png` is a raster atlas of nine original action illustrations generated with the session's native `image_gen.imagegen` tool on 1 October 2026, following the user's request to generate creative game art. The native tool's default model was used; no external provider account, paid API, third-party reference image, brand, franchise, or real-person likeness was supplied. This record does not claim a specific model version or CC0 licensing.

The PNG is 1254 × 1254, RGBA, with genuine alpha transparency. SHA-256: `6dd42256ad93ae7e06ff9292530457b5a748d0b9fbdd536f264f7584cd9a735b`.

The illustrations depict smash, dash, jump, craft, block, grab, place, drop, and swap. `GameHud.Icon` slices measured rectangles around each silhouette rather than assuming a perfectly aligned grid. The middle column required a different horizontal cut to keep the shield and drop icons separate. The original raster is preserved without post-generation image edits. These are 3D-style interface illustrations, not meshes. They have no colliders, animations, or game rules; the associated touch controls send the same commands as the physical controls.

The separately generated house-and-garden arena illustration is art direction reference only. It is not a playable screenshot or an integrated map, and it is not included in the game assets.

`Assets/_Project/Resources/UI/Items/*.png` contains forty 192 × 192 transparent thumbnails rendered in Blender from the supplied item meshes and their restored PBR materials. These are previews of the actual model assets, not AI generations or replacements for those meshes. The craft drawer uses the matching thumbnail for each recipe and dims previews whose letters are missing.
