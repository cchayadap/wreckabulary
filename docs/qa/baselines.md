# Wreckabulary: baseline changes

Append only. Every change to a visual golden or a performance baseline gets one entry here: UTC time, which baseline, old and new value or file, the reason, and the change or build it came from.

Golden images move from `Docs/qa/golden/current/` to `Docs/qa/golden/approved/` only after the owner approves them. Updating a baseline to make a failing check pass, without a reason the owner accepted, hides a regression.
