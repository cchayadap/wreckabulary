# Gate card M0: Bootstrap

The machine-checked rows are in `Docs/qa/gates.json` (milestone `M0`); this card says how to run each one. Close only with `node Tools/kit/harness/gate_close.mjs M0`. Verdicts: PASS, FAIL, BLOCKED, NOT-RUN.

M0 proves that every tool works on this machine and produces a correct result, not merely that it answers. A tool that only "responds" hid two costly bugs in an earlier run: prompts cut at the first newline, and inputs saved as outputs.
