## Lifetime and resource bounds

`FeedbackBurst` pools at most six instances per named imported effect. Normal use reuses these instances; inactive objects are retained under `World.Transient` until round cleanup. Dead or previous-round references are removed before reuse. Mesh bursts last 0.12–1.2 seconds, use cached camera transforms and property blocks, and do not clone renderer materials. The generated `Resources/UI/Generated/impact-spark` texture is loaded once and used by a shared runtime Sprite; its static state resets between play sessions. Supplied meshes remain the fallback if that texture is unavailable.

House floor detail uses one generated mesh per indoor floor. Those meshes are destroyed with the corresponding `HousePresentation`. New deployed indicators are children of their owning tool and are destroyed on pickup. FOAM shares `SummonedThing` token/lifetime cleanup. SOAP shares the existing patch lifetime. Clear-out ribbons share phase/reset cleanup. Bomb audio clip state now resets between play sessions.

Letter pickup visuals reuse each tile's imported art and one line halo. Three shared emissive materials cover the three rarities and reset between play sessions. `LetterPickupViewTests.FloatingPickupPreservesPhysicsAndResetsWhenReused` was added to check the rigidbody/collider invariants, distance return and pooled component reuse; execution belongs to the coordinator's Unity run.
