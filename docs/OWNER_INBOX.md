# Wreckabulary: owner inbox

Written only by the UserPromptSubmit hook (`Tools/kit/hooks/owner_inbox.mjs`). Every owner prompt lands here with a UTC time and an inbox number, after secrets are redacted. Do not edit this file: deny rules and the guard refuse it.

The agent acknowledges an item by appending a line to `Docs/owner_acks.md`. Owner commands the hook applies: `OWNER: pause`, `OWNER: resume`, `OWNER: stop`, `OWNER: confirm <row, CR-n or GH-n>`, `OWNER: unlock harness`, `OWNER: lock harness`, and `OWNER-OVERRIDE: <exact command>`.
