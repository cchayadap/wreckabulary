## Boss Fight — runtime crash fix (NameToLayer in static initializer)
- User hit `UnityException: NameToLayer is not allowed to be called from a MonoBehaviour constructor (or instance field initializer)`. Source: `MiniCalculator` line 26 `static readonly int SolidLayers = SolidMask();` — a static field initializer calling `LayerMask.NameToLayer`, which throws during type initialization on `AddComponent`, so `TickMinis` could never create a mini.
- Fix: removed the static initializer; `solidMask` is now an instance field starting at -1 and built lazily inside `CanOccupy()` (first runtime call). `SolidMask()` itself is unchanged and still uses `NameToLayer`, but now only runs at runtime.
- Audited other `NameToLayer` uses: `World.PlayerLayer` / `TileLayer` / `TileMask` are expression-bodied properties (evaluated on access), so they are safe. No other static field initializers call Unity APIs.
- No design/config change, so freeze stays v12 / trace 42/42. Both builds 0 errors (pre-existing warnings only). No Editor PlayMode run.
