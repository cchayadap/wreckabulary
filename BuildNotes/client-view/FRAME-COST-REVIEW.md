## Why full reconciliation cannot simply be skipped

The exact path is `WordboundGameplayDriver.FixedUpdateNetwork` → `PrepareHostPhysics`; native physics then invokes `WordboundPhysicsWorld.AfterSimulate` (line 480) → `AdvanceHost` (Controller line 254) → `Authority.Advance` → `CaptureFrame` → `Reconcile` → `ReconcileAndApplySnapshot` → `ApplyValidatedSnapshot`. AfterSimulate explicitly rejects a completed step unless its canonical revision was applied before another physics step. That application updates active/kinematic state, consumed or spawned bodies, collision ownership, authenticated input seats, poses/velocities and item modes. Merely publishing once per Unity frame would leave intervening physics ticks using stale state.

`AuthoritativeMatch.Advance` (line 184) validates individual operations, captures a rollback baseline and restores it on failure; it does **not** already execute the complete `MatchStateValidation.Validate` on each successful tick. The full validation inside atomic reconciliation is therefore not a duplicate of an earlier equivalent full check. The atomic path already performs only one full validation, followed by the five mutable-dependency phases after the Prepare callback. Rules/catalogue and public callback effects can change across that boundary. Removing either pass, introducing a public trusted-snapshot bypass, or treating the previous immutable snapshot as current proof would weaken existing abort/reentry/mutation guarantees. Public `ApplySnapshot`, replica import, checkpoint publication/import and recovery must retain full validation.

The cheap `MatchesTickPresenceAndResult` comparison already suppresses unnecessary complete Capture/Reconcile calls in Poll and PrepareHostPhysics; it checks same-tick presence and terminal confirmation. It is intentionally not a general snapshot-validity token. Reusing that snapshot as Advance's rollback image is not established safe: current public presence/result/recovery and other out-of-tick state paths require separate lifetime/version proof. The post-advance capture and the pre-advance rollback capture serve different states.
