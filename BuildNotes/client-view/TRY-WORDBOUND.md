# Try the refined lobby

Open [Wreckabulary.exe](../../Builds/qa-20261026T164019Z/Wreckabulary.exe). Keep the complete build folder together. This is a tested QA-enabled Windows review build.

1. **Play → Local** — pick a mode and house. One short summary tells you the objective and actual humans/bots. **Go** starts the selected local match.
2. **Customize / Shop** — preview your original character, outfit and equipment. Shop is now labeled beside the coin balance. Purchases use earned coins and your real local save.
3. **Settings** — Profile, Audio, Gameplay, Graphics, Controls or Help. Long lists have a visible scrollbar; Controls retains the existing remapping and cancellation behavior.
4. **Play → Create** — choose learning or the home-building workshop. **Play → Online**, or Home's **Online Play**, opens the actual Wordbound frontend. Connect there to use its public/private party flow. Public matchmaking needs other people; it does not silently substitute bots.
