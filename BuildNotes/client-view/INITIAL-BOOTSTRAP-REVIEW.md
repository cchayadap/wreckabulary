Scope: `WordboundFusionSession`, pure `OnlineBootstrapBarrier` beside `OnlineSessionGate`, 17 added Rules cases and the actual shared native initial-start/first-advance observer. Purpose is to prevent host canonical gameplay from starting before every original remote seat has imported and acknowledged the exact durable bootstrap; it does not change transfer age, canonical tick rate, SDK scheduling, memory capacity or reconnect deadlines.

Source sequencing is noncircular: the client receives an admitted snapshot, restores and completely validates it, invokes ReplicaReceived (whose controller imports the exact canonical frame), sends SnapshotAck, then calls TryClientBegin. ACK therefore does not require Begin, client GameplayReady or native gameplay bodies. Host BeginAfterCheckpoint refreshes authorization, commits the bootstrap and seeds election, then waits for the exact receipts before setting GameplayReady and sending Begin. No gameplay tick is required to satisfy the barrier; the existing election marker's SDK tick remains separate.

The barrier is created in CommitPublication before SendCommitted can deliver packets/ACKs. It holds an exact immutable snapshot mark, RunScope owner reference and copied distinct required-remote-peer set, excluding local host; an empty mutable send queue cannot substitute for evidence. Existing gate/sent-mark validation still precedes new receipt counting. Wrong owner/peer/mark and duplicate wire ACKs cannot count toward release; accepted remote ACK events remain observable by the existing fixture. No received token, payload, peer identity or mark hash is newly logged.

Original startup deadline is the exclusive match-start+90,000 ms bound, retained while InitialStarting even after gate.TryStart sets Started. The wait uses cancellable asynchronous 20 ms delay; each iteration and final release checks current scope, original writer term/live writer, running host, complete ready original roster, and pinned admitted peer/actor/connection/epoch/host identities against current unexpired leases. It does not pin a lease object or old expiry value, so ordinary lease renewal is not treated as identity replacement. InvalidateRun cancels the barrier; a pinned peer leaving cancels it, and changing the ready roster cannot become a reduced successful set. A late accepted-ACK callback cannot release a stopped/superseded scope because the final path rechecks it.

Only requiresCompleteRoster initial start constructs/waits this barrier. Existing gate.Started migration/rejoin paths skip it and retain their survivor/reconnect rules. The native addition observes the real first host GameplayStarted: exact initial tick0 committed mark, zero advances, every actual replica's imported mark and every exact host ACK.
