# Native Photon custom authentication proof

STATUS: R0 REFERENCE COMPILE PASS; NATIVE EXECUTION NOT RUN

Scope: new editor-only native fixture under `Assets/_Project/Tests/PhotonAuth`. Root is the sole Unity operator. No dashboard or provider configuration changes are performed by this lane or fixture.

The fixture is explicitly gated by `WORDBOUND_EXTERNAL_PHOTON_AUTH=1` and NUnit category `ExternalPhotonAuth`. Without the variable the three cases report NOT RUN/ignored, before guest creation or cloud access. With the gate set, missing/mismatched production configuration is a failure.

It reads the approved non-secret `OnlineServices/production-client.json`, pinned to the deployed coordinator origin and Fusion app. Each legitimate Runner receives a freshly issued guest identity and one-use Photon ticket through actual `OnlineCoordinatorClient` and `WordboundHttpTransport`. The endpoint is plural: `POST /v1/photon/tickets`. No provider secret or private signing material is required.

Cases:

- Start a private custom-auth host and client; assert server-side callback and live `GetPlayerUserId` mappings equal both coordinator UUIDs. An arbitrary client-requested UserId must be replaced by the provider's identity.
- Start a valid custom-auth host as a positive control, then require a fresh anonymous Runner to fail with an authentication-specific reason before host admission.
- Repeat the positive control, then require a fresh custom-auth Runner with an invalid ticket to fail the same way.

Timeouts, room capacity, connection refusal, cancelled startup or an unavailable network cannot satisfy the negative cases. The fixture never disables the provider. It bounds HTTP/startup/roster waits and teardown, cancels outstanding tasks, clears in-memory client credentials, shuts down only uniquely prefixed proof runners, restores build scenes and restores its scoped expected-authentication log handling. Raw HTTP/SDK error messages, tokens and authentication response dictionaries are not printed or saved. AuthenticationValues' installed SDK `ToString` reports only whether post data exists.

Use root's existing native scene `Assets/_Project/Tests/Photon/WordboundPhotonProof.unity`, generated by `Wreckabulary.EditorTools.WordboundPhotonSetup.CreateProofScene`. The fixture has its own scene-settings recovery key and does not call another test assembly's internal helpers. Modern TestRunner references and explicit Fusion runtime/common/sockets/realtime/log precompiled references are included.

Acceptance is the final native NUnit result including teardown. Sanitized observation logs are explicitly marked cleanup pending and are not standalone PASS artifacts. Native provider handshake, anonymous rejection and invalid-ticket rejection remain NOT RUN until root configures the provider and executes the gated suite.
